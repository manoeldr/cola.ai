# Cola.ai mobile

Versão consolidada do aplicativo Expo com importador V6, câmera, histórico, biblioteca de disciplinas e resumos no backend C#.

Execute `npm ci` e `npx expo start`. Configure o backend pela página local `/mobile-setup`. Nenhum dado de uso ou credencial está incluído no repositório.

A resolução de fotos no aplicativo ainda não foi conectada; a captura e o histórico são locais.
